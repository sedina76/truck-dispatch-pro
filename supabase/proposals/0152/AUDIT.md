# Idempotent-RPC audit (0135-0147) -- proposal 0152

Method: (1) the LIVE bodies of every function that references an idempotency ledger were dumped from the scratch chain 0130..0147 and read; (2) EXECUTE privileges were measured on a scratch
cluster that emulates Supabase's schema-level default privileges (`alter default privileges in schema public grant execute on functions to anon, authenticated, service_role`, see 0127);
(3) every suspected defect was reproduced on the real functions with known target ids and keys (`matrix.sql`, 8 RPCs x 16 steps, run on the baseline and after 0152); (4) the ten 0144-0147
RPCs that needed no repair are proven safe by RUNTIME probes (`probe_safe_0144_0147.sql`: 16-17 expectations per RPC, run on the baseline and after 0152, identical results), structurally on their live bodies (`tests.py: audit_live_order`) and by the repository's own suites, which pass with 0152 injected.
"Order" = the sequence of checks before the first ledger read. Every function is `SECURITY DEFINER` with `search_path = pg_catalog, public` except where noted.
EXECUTE column = anon / authenticated / service_role / PUBLIC, measured with Supabase-style default privileges.

Additional privilege findings (baseline, Supabase default privileges): `anon` retains EXECUTE on `transition_dispatch_status`, `reassign_dispatch_resources` and `set_carrier_factoring_policy`
(their migrations `revoke ... from public` only). All three refuse `auth.uid() IS NULL` in-function (TSAUT / RRAUT / FPAUT), so this is exposure in principle, not exploitable; **not changed by 0152** (out of scope).
`service_role` retains EXECUTE on the pure predicates and guard functions revoked only from public/anon/authenticated (0141, 0142, 0143, 0145, 0146): they have no client path and give service_role nothing it does not already have
(it can write any table directly), so only the three helpers that mint numbers, run a lifecycle write, or trust caller-supplied identity are revoked.

No application code calls any of the three internal helpers (`grep` over `src/`; asserted again in `tests.py`).
