# Proposal 0154 -- finding F-05 (unsafe function exposure) -- NOT APPROVED FOR PRODUCTION, NOT APPLIED

`record_unresolved_carrier_record()` (0130) treated a NULL `auth.uid()` as a trusted migration context and was revoked only from PUBLIC. On Supabase, default privileges grant EXECUTE on new public functions to `anon`, `authenticated` and `service_role`, so an unauthenticated PostgREST caller could write exception rows for any organization (reproduced by `tests.py`). The application never calls the function (no call site in `src/`); the only callers are migrations 0133 and 0137, run by the owner.

It refuses on any unexpected overload/twin, owner, body or signature and never touches an exception record. `preflight.sql`, `post_apply.sql`, `rollback.sql` (restores the exact 0130 definition; refuses if 0155 is applied), `build.py` (extracts the baseline from 0130, pins its md5).
