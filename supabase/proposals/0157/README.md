# Proposal 0157 -- F-08: carrier-invoice issuance, reissue and factoring (Owner decisions D-08a..i, D-57a..h) -- NOT APPROVED FOR PRODUCTION, NOT APPLIED, GATE DISABLED BY DEFAULT

Applies only to `carrier_invoices`. Requires 0155 (and therefore 0154); applies after 0152; coexists with a disabled 0156 (refuses if the legacy gate is enabled). See `OWNER_DECISIONS.md` for the final decisions, the workflow, the dispatch-fee treatment, the authorization matrix and the existing 0144 privilege boundary. D-57h records the owner/admin-only pilot: only owners/admins may issue, reissue or submit to factoring. Granted dispatchers may preview and prepare drafts (ready/discard included), never submit. The signed-off 0144 function stays unchanged and factoring stays disabled.

**Tables** (all `_0157`-suffixed until promotion; foreign keys all `ON DELETE RESTRICT`): `carrier_invoice_factoring_gate_0157` (operator gate), `carrier_factoring_submitter_grants_0157`, `carrier_invoice_factoring_submissions_0157` (statuses submitted / withdrawn), `carrier_invoice_factoring_snapshots_0157`, `carrier_invoice_factoring_audit_0157` (append-only, hash-chained), `carrier_invoice_issuance_terms_0157` (immutable facts frozen at issuance), `carrier_invoice_workflow_ops_0157` (idempotency records), `carrier_invoice_billable_ledger_0157` (a load is live on at most one invoice), `carrier_invoice_reissues_0157` (original -> replacement link + immutable reason), `carrier_invoice_dispatch_fee_links_0157`.

**RPCs** (authenticated only; PUBLIC/anon/service_role revoked; fully qualified objects; `search_path = pg_catalog, pg_temp`): factoring `preview_carrier_invoice_factoring`, `submit_carrier_invoice_to_factor`, `withdraw_carrier_invoice_factoring_submission`, `set_carrier_factoring_submitter`; issuance `preview_carrier_invoice_issuance`, `create_carrier_invoice_draft_from_loads`, `mark_carrier_invoice_ready_for_issue`, `discard_carrier_invoice_draft`, `issue_prepared_carrier_invoice`, `preview_carrier_invoice_reissue`, `reissue_carrier_invoice`. No RPC takes a relationship, factor, routing, organization or amount parameter.

**Files:** `proposed_0157.sql` (hand-maintained), `preflight.sql` / `post_apply.sql` / `rollback.sql` (generated by `build.py`; `--check` verifies), `fixture_carrier_invoices.sql` + `fixture_issuance.sql` (synthetic), `tests.py` (disposable local PostgreSQL only), `normalize_names.py` (D-57f). App side: `src/lib/factoring/carrier-invoice-{submission,issuance}.ts` (+ tests), `src/app/(app)/carrier-invoices/**`, `src/components/carrier-invoices/**`.

**Rollback** removes the RPCs, helpers and the gate; every history table (and its immutability triggers) is KEPT whenever any of them holds a row.
